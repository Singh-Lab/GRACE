# Examples

Each file runs end to end once the models are downloaded. They use paths
relative to the repository root, so run them from there:
`bash examples/01_first_design.sh`, not `cd examples && bash 01_...`.

| File | What it shows |
|---|---|
| `01_first_design.sh` | the shortest useful command |
| `02_tolerance_sweep.sh` | the same start at five tolerances |
| `03_compare_methods.sh` | GRACE against four baselines at a matched budget |
| `04_your_own_sequence.py` | the Python API on a sequence of your own |
